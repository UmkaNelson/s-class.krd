# S-Class Краснодар — новый сайт (черновик)

Макет сайта фитнес-студии S-Class (Краснодар) в стиле брендбука.

- `index.html` — главная
- `directions.html` — 16 направлений с фильтром по сложности
- `studios.html` — адреса и контакты студий
- `data.js` — все тексты: направления, студии, абонементы, отзывы
- `site.js` — общая шапка, меню, блок записи и подвал
- `style.css` — общие стили
- `img/` — фотографии направлений

Тёмная версия включается ссылкой `?t=dark`. Это макет: формы заявок не отправляются, страницы закрыты от индексации.
