# S-Class Краснодар — варианты главной страницы

Черновики дизайна главной страницы сайта фитнес-студии S-Class (Краснодар).

- `d.html` — вариант по брендбуку, светлый; `d.html?t=dark` — тёмный
- `a.html`, `b.html`, `c.html` — первый заход, до брендбука
- `data.js` — общие тексты и ссылки на фотографии

Это макеты: формы заявок не отправляются, страницы закрыты от индексации.
